QuizMaster - Quiz and Score Analysis System

1. Introduction

A small console quiz project for CSE1021 (Introduction to Problem Solving and Programming). You get 10 multiple choice questions, then a score report with grade and percentage. The program also has a score analysis screen and a number analysis screen (prime check, prime factors, GCD and Fibonacci)

2. Syllabus Units Used

The project is based on the following units from the syllabus:

- Unit 3: Fundamental Algorithms and Python Control Flow
- Unit 4: Factoring Methods
- Unit 5: Array Techniques and Python Lists

These concepts are used in different parts of the program for conducting the quiz and analysing the results.

3. Features of the Project

The main features included in our QuizMaster project are:

- Selecting MCQ questions randomly
- Checking whether the user's input is valid
- Calculating the total score
- Calculating the percentage obtained
- Giving a grade based on the score
- Allowing the user to review their answers
- Finding the frequency of different scores
- Finding the highest, lowest, and average score
- Checking for duplicate scores
- Arranging students based on their performance
- Checking whether a number is prime
- Finding prime factors
- Calculating GCD
- Generating Fibonacci numbers
- Using Python lists, sets, and dictionaries for storing and processing information

4. Requirements

To run this project, we need:

- Python 3.x
- A computer or laptop with Python installed
- A Python editor or terminal

No external Python packages are required for this project.

5. How to Run the Program

First, open the project folder in the terminal.

Then run the following command:

python quiz_score_analysis.py

After running the program, the user can follow the instructions displayed on the screen and use the available quiz and score-analysis options.
